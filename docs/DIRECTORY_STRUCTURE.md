# ディレクトリ構造定義書 (DIRECTORY_STRUCTURE.md)

## 1. 全体構造と役割

プロジェクトの主要なディレクトリと、本システムにおける役割の定義です。

| パス | 役割・格納データ | 備考 |
| :--- | :--- | :--- |
| **`app/Http/Controllers/`** | 通常の画面遷移や制御を行うコントローラー | 直下は一般ユーザー向け画面など |
| ├── **`Admin/`** | 管理画面専用のコントローラー | 管理者権限が必要な機能 |
| ├── **`Api/`** | Phaser（ゲーム）や外部連携用のAPIコントローラー | JSON応答を返すエンドポイント |
| └── **`Auth/`** | ログイン、会員登録、パスワードリセット等の認証制御 | ユーザー管理の基盤 |
| **`app/Models/`** | 各データベーステーブルと1対1で対応するモデル | ビジネスロジック、データ操作 |
| **`app/Helpers/`** | システム全体で使い回す共通処理の関数群 | ヘルパーファイル（手動読み込み設定） |
| **`app/Console/Commands/`** | 常駐バッチや職人コマンド（Artisan） | `MqttListener.php`（MQTTリッスン）など |
| **`config/`** | アプリケーションの外部定義設定値 | デバイス定義、APIキー、共通設定など |
| **`database/migrations/`** | DBのテーブル構造を管理する定義ファイル | マイグレーションによるスキーマ管理 |
| **`public/`** | 外部に公開される公開領域 | ビルド成果物、画像、音声、storageリンク |
| **`resources/views/`** | Bladeテンプレート（画面のHTML） | フロントエンドの表示領域 |
| **`routes/`** | ルーティング定義（URLと処理の紐付け） | `web.php` / `api.php` |
| **`storage/app/game/`** | ゲーム設定JSON、または内部データーベース | Phaserが読み込むステージや難易度設定 |

## 2. 独自実装ルールと重要コンテキスト

### ① `app/Helpers` (共通処理) の役割
システム全体で頻繁に呼び出される以下の処理は、Controllerに直接書かず、必ず `Helpers` 内に共通関数として実装・拡張します。
* エラーログの書き込み（例: `make_error_log()`）
* メール送信処理
* プッシュ通知送信処理（例: `push_send()`）
* 楽天アフィリエイト広告の制御・取得

### ② 設定値 (`config/`) の管理
マジックナンバー（コード内に直接書く数値や文字）を排除するため、デバイスの種類やシステムの挙動フラグは `config/` 内の設定ファイル（例: `config/common.php` や `config/services.php`）に定義し、`config('ファイル名.キー')` で取得します。

### ログ出力に関する重要規約
デバッグおよびエラー特定の迅速化のため、`make_error_log` を使用する際は、**各メソッド（関数）の冒頭で必ず以下の形式でログファイル名を定義**してください。固定の文字列（例: `"subscribeMQTT.log"` など）を直接指定することは原則禁止とします。

```php
$error_log = class_basename(__CLASS__) . '_' . __FUNCTION__ . ".log";
